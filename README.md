# Employee Attrition Prediction & HR Analytics

A Machine Learning project that predicts employee attrition using IBM’s fictional HR Analytics dataset and presents insights through an interactive Streamlit dashboard.

## Features
- Exploratory Data Analysis
- Data preprocessing and feature engineering
- Logistic Regression, Decision Tree, and Random Forest
- Model evaluation and comparison
- Interactive HR analytics dashboard
- Employee attrition prediction

## Tech Stack
Python · Pandas · NumPy · Scikit-learn · Streamlit · Matplotlib · Plotly

## Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## Dataset
IBM HR Analytics Employee Attrition & Performance  
[Dataset Source](https://github.com/IBM/employee-attrition-aif360)

> This project uses fictional data and is intended for academic purposes only. Predictions should not be used to make employment decisions.
